# Spec #3 — Core UX Replication (legacy, verbatim)

**Date:** 2026-05-30
**Branch:** `worktree/refactor/massive-refactor`
**Part of:** [SSR Refactor Program Roadmap](./2026-05-30-ssr-refactor-roadmap.md)
**Depends on:** Spec #1 (SSR), Spec #2 (concept board). **Status:** Design.

## Goal

Replicate the legacy frontend UX **verbatim** on the Next.js foundation: onboarding, the home
hub, the 3-stage workbench, the library grouped by brand, the rail, the start modal, the success
toast — matching legacy layout, copy, and behavior. Fold in the two requested improvements:
a discoverable **cog → sign-out popup** and an **add-client back button**. Complete the migration
off `react-router-dom` and remove it.

## Scope

### Screens to build (legacy parity)

- **Onboarding** (`/onboarding` or first-run gate): `url → analyzing → goal` steps, legacy copy.
  **Improvement:** a **Back** button on each step after the first (legacy had none) so a mistyped
  URL / wrong goal is recoverable. The goal step writes `brand_extractions.goal` (column from
  Spec #2) via `PATCH /api/brand/:id/goal`.
- **Home / hub** — greeting + entry points (Make an ad, my ads, saved brands), legacy layout.
- **Workbench** (`/create`) — rebuild the 3-stage flow verbatim:
  1. *Analyzing* (new brand): extract → brand → (auto-fill logo) → stage 2.
  2. *Pick reference*: reference-ad dropzone + logo dropzone (required) + optional product
     screenshots; "back" + "make my ad" (disabled until ref + logo).
  3. *Pick angle*: angle list (radio rows), preview strip with thumbnails, per-angle render on
     click, "back" + "ship". Success → toast + return to hub.
  Consumes the selected concepts handed off from the board (Spec #2) as the creative direction.
- **Library / my ads** (`/library`) — grouped by brand domain, legacy card layout, instant load
  via the Spec #1 cache (stale-while-revalidate), "new ad" → start modal.
- **Start modal** ("Which brand?") — URL field + saved-brand list; opens from rail/library.
- **Rail** — legacy nav (home, make an ad, my ads + count, brands + count, add client) + saved
  brands section + user footer card.
- **Success toast** — "Ad saved! [angle]", auto-dismiss ~4.5s.

### Improvements

- **Cog → sign-out popup:** the user footer shows a cog; clicking opens a small popover/menu with
  "Sign out" (and email). Replaces today's always-visible "Sign out" text — makes the affordance
  match legacy while being discoverable. Accessible (button + dismiss on outside-click/Escape).
- **Add-client Back button:** see onboarding above.

### Routing migration (finish + remove react-router)

- Migrate `Workbench` and any remaining components off `react-router-dom`
  (`useNavigate`/`useSearchParams`/`Link` → `next/navigation` + `next/link`).
- Replace the Spec #1 stub pages (`/create`) with the real workbench.
- Once no file imports `react-router-dom`, **remove it from `apps/web/package.json`** and verify
  `npm run build` + grep shows zero imports.

### Styling

The design tokens (`tokens.css`) and component classes (`app.css`) already mirror the legacy
system (cream/ink/blue, DM Sans, `.btn/.stage/.rail/.dropzone/...`). Replicate legacy markup using
these classes; add any missing legacy component CSS (e.g. focus strip, angle rows, toast, popover)
to `app.css`. Use the `ui-ux-pro-max` skill only if needed to hit pixel fidelity.

## Non-goals (later specs)

## Architecture notes

- Workbench keeps its client-side state machine (`src/workbench/state.ts` reducer is reusable);
  rewire data calls to the existing `api.*` (extract/brand/ad-prompt/render or batch). Heavy
  client interactivity → all `"use client"`.
- Onboarding state is client-side; the goal write hits the Spec #2 endpoint.
- The cog popover is a small client component (no new dependency — plain React + an
  outside-click/Escape handler).

## Testing

- Onboarding: step transitions; **Back** returns to the previous step with prior input intact.
- Workbench: stage gating (make-my-ad disabled until ref+logo; ship enabled after a render);
  reducer transitions covered.
- Library: grouped-by-brand rendering; instant render from warm cache.
- Cog popover: opens on click, shows Sign out, closes on outside-click/Escape, triggers `signOut`.
- Post-migration: a test/grep asserting no `react-router-dom` import remains.

## Acceptance criteria

1. Onboarding, home, workbench, library, start modal, rail, toast match legacy behavior/layout.
2. Add-client flow has a working Back button; cog opens a sign-out popover.
3. `react-router-dom` is fully removed; `npm run build -w @bya/web` passes with no react-router.
4. `npm test -w @bya/web` passes.
